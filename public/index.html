How to use

Three steps — no key system, no ads, no waiting.

1

Get an executor

Install a Roblox script executor that supports loadstring and HttpGet (Synapse Z, Wave, Delta, Codex, Solara...). Mobile executors work too.

2

Copy a loadstring

Tap COPY on any card above — the command already points at this site, nothing to edit.

3

Execute in-game

Join the game, paste the loadstring into the executor window and press Execute. The THORHUB GUI appears instantly.

Adding a new game

Site-owner workflow — upload a file, and this page rebuilds itself.

  1. Open public/scripts on GitHub, then Add file → Upload files.
  2. Create a folder named after the game (type game-name/ in the filename box) and drop your .lua inside — e.g. public/scripts/pet-sim-99/ThorHub.lua.
  3. Optional: add an info.json in the same folder to set the card title, description, version and status badge (working / maintenance / down).
  4. Commit — GitHub Actions regenerates this page and Vercel deploys it in about a minute. The new loadstring goes live at https://thorhub.vercel.app/scripts/game-name/ThorHub.lua.
